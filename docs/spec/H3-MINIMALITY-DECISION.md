## Adjudication

**(a) Direct native subset growth — CONTINUE, metered.** This is not a
choice; it is the observed trajectory (A2's emitter grew 8× doing exactly
this, with A3 independently gating each step). The decision is only the
METER: next step = Candidate-A vertical, then re-measure reachable fraction
before any further widening. No new authority, no schema change, no budget
change. Engineering complexity does NOT hide in the host here — the emitter
already reifies every gate as `pep_c23_unsupported` with a message (fail-closed
by construction, H1-R4/58fc9bf reads).

**(b) Compiler-derived checkpoint — KEEP PRESENT DESIGN (gated).** Bug-class
evidence is real (O1c/A1b), Typedtree precedent exists, Matthew's priority
aligns — and NONE of it prices the seam. Without F-B, adopting (b) now risks
moving cost from N passes into one unmeasured checkpoint schema + a
lockstep-upgrade obligation on every consumer. Revisit trigger (unchanged
from E3): F-B positive + lanes between gates + explicit go-ahead.

**(c) Reduce transitive deps via Pep libraries — KEEP PRESENT DESIGN
(gated).** F-C unmeasured; the one executed data point cuts AGAINST (c):
P3's recursive quicksort PASSES under the interpreter, i.e. the current
"expensive" dependency (runtime recursion over lists) already works where it
runs. Demoting builtins to Pep would move PROVEN-working native code into
unmeasured interpreted loops. Revisit trigger: F-C measured on `int_text`
(softest target) showing <3× step cost with byte-identical outputs.

## The one cheapest experiment

Run H2-Candidate-A through A2's harness (affected: A2 executes, A3 oracles).
Success metrics: (1) identical outputs seed/Clang/GCC on the two probes;
(2) refusal-or-green lands within ONE existing gate (no new diagnostic
family). Failure criteria: (1) refusal requires a NEW trusted primitive
outside the named fn set (scope creep — stop, re-price); (2) outputs diverge
across toolchains (correctness block — stop, file to A2/A3, no retry-as-green).
Evidence to capture: exact refusal code or triple-output equality + A2 SHA +
toolchain versions. Cost if green: near-zero (extends H1 reachability count).
Cost if red: exactly one named gate (feeds the next H2).
